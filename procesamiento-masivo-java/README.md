## Descripción del problema

El programa original utiliza listas y búsquedas lineales para agrupar campañas, lo cual afecta el rendimiento cuando se procesan grandes cantidades de clientes.

## Problemas detectados

- Alto consumo de memoria.
- Búsquedas lineales lentas.
- Menor eficiencia al aumentar registros.

## Solución implementada

Se utilizó HashMap para agrupar campañas de manera más eficiente y mejorar el tiempo de procesamiento.

## Comparación de resultados

La versión optimizada mejora la organización y el procesamiento de clientes usando estructuras más eficientes.

## Conclusión

El uso adecuado de estructuras de datos mejora significativamente el rendimiento y el manejo de memoria en aplicaciones de procesamiento masivo.
